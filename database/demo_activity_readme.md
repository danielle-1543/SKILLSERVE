# Generated activity batch

This dataset is synthetic, generated for development and AI-pipeline prototyping. It is not actual customer feedback or independently verified outcomes. Keep the source label when exporting, and do not use these records as a real-world evaluation benchmark.

The adjacent demo_activity_manifest.json lists all generated IDs, fictional clients and workers, and review-to-booking scenario links. The current application does not yet have a booking foreign key on reviews; those links are recorded in the manifest rather than enforced in that model.

Created: 79 worker reviews (3–5 per fictional worker), 79 work posts (3–5 per worker), 21 upcoming job offers (3–5 per fictional client), 42 job comments, 79 completed bookings and their status histories, and pre-booking messages. No reviews were added to real user profiles. No payments, uploaded proof, or independently verified credentials were generated.
